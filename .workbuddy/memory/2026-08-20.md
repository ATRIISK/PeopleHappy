## 五大卖点（按面试含金量排序）

1. 并发安全：乐观锁扣库存 + 条件更新状态机 + 购物车 upsert + 退款幂等（防超卖/防重复回调）
2. RabbitMQ 原生 TTL + DLX 死信延迟队列实现订单 30 分钟超时取消
3. Redis 缓存体系：@Cacheable + 延时双删 + ZSet 热榜 + CacheErrorHandler 故障降级
4. 支付宝沙箱完整支付闭环：precreate 扫码 + RSA2 验签 + 主动查询兜底 + 退款幂等
5. AI RAG 购物助手：关键词 + embedding 混合检索、增量同步、无 key 优雅降级（2026 求职热点差异化）
