# Codex 经典灰白工作台 UI 设计

日期：2026-10-31
状态：已确认 A 方案，待实现
范围：`E:\PeopleHappy\happy-mart-web`
取代：`2026-10-31-codex-dark-ui-design.md`

## 1. 目标

把现有黑绿深色主题替换为 Codex 经典浅灰白界面，并将前台布局从传统电商横幅页调整为更接近桌面工作台的侧栏结构。

改造只涉及展示层。接口、Pinia 状态、路由、工具函数、后端和数据均保持不变。

成功标准：

1. 页面以灰白、白色、浅灰边框和近黑文字为主，不再出现黑绿主视觉。
2. 桌面端有稳定的左侧导航栏、紧凑顶部工具栏和白底主内容区。
3. 首页、商品页、交易页、AI 助手和后台使用同一套灰白视觉语言。
4. 390 像素视口下无横向溢出，移动端侧栏可收起。
5. 构建通过，公开页面完成浏览器实拍验收。

## 2. 视觉语言

### 2.1 配色

| 用途 | 色值 |
|---|---|
| 页面底色 | `#f7f7f8` |
| 侧栏底色 | `#f2f2f3` |
| 内容表面 | `#ffffff` |
| 次级表面 | `#f9f9fa` |
| 悬停表面 | `#ededef` |
| 普通描边 | `#e5e5e7` |
| 强描边 | `#d4d4d8` |
| 主文字 | `#202124` |
| 次文字 | `#5f6368` |
| 弱文字 | `#8a8f98` |
| 主按钮 | `#202124` |
| 焦点色 | `#4f8ef7` |
| 危险色 | `#d93025` |

价格和重要金额使用近黑强文字，危险操作才使用红色。蓝色只用于键盘焦点、链接和选中状态，不铺满页面。阴影非常轻，主要依赖细边框区分层级。

### 2.2 字体和形状

- 字体保持系统中文字体栈，标题可叠加 `Cascadia Code` 作为轻量工具感点缀。
- 卡片圆角统一为 8 至 12 像素。
- 页面区块使用白色表面、1 像素浅灰边框和极浅阴影。
- 按钮以黑底白字、白底黑字和透明幽灵按钮为主。
- 去除网格背景、霓虹光、终端闪烁、扫光和黑绿渐变。

## 3. 布局

### 3.1 桌面端

- 左侧固定导航宽 224 像素，包含 Logo、首页、商品、购物车、订单、地址和用户入口。
- 侧栏使用浅灰底，选中项使用白色表面、黑色文字和左侧细指示条。
- 主区域包含 52 至 60 像素的顶部工具栏，搜索框、登录注册和用户菜单集中在右侧。
- 主内容使用 `#f7f7f8` 页面底色，内容块为白色卡片，最大宽度约 1280 像素。
- 首页首屏改为白底编辑式 Hero：左侧文案和操作，右侧商品图，不再使用大面积促销横幅。
- 商品网格使用白底卡片和细边框，悬停只做轻微上移和边框加深。
- AI 助手保留现有触发和请求逻辑，面板改成右侧浅色侧边面板，风格与 Codex 对话区一致。

### 3.2 移动端

- 左侧栏改为顶部抽屉，由菜单按钮打开。
- 搜索和用户操作保留在紧凑顶栏。
- 商品卡片采用两列，窄屏商品详情改为单列。
- 所有页面不得产生横向滚动。

### 3.3 后台

- 后台侧栏与前台侧栏统一灰白层级。
- 表格、表单、弹窗、分页和下拉菜单使用白色表面与浅灰边框。
- 后台信息密度高于前台，但颜色和形状保持一致。

## 4. 动效

只保留四类轻量反馈：

| 场景 | 动效 |
|---|---|
| 页面首次进入 | 160 至 220 毫秒淡入 |
| 卡片悬停 | 上移 2 像素，边框加深 |
| 按钮悬停 | 背景和文字颜色过渡 |
| 搜索/表单聚焦 | 蓝色焦点描边 |

移除持续闪烁、扫光、网格光晕和长时间脉冲。支持 `prefers-reduced-motion: reduce`。
