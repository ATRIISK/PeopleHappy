## 1. 项目概述

众乐电子商城是一个轻量级 B2C 电商平台，包含用户端（商品浏览/购物车/下单/微信扫码支付）和管理后台（商品/订单/用户管理）。项目采用 Java Spring Boot 3 + Vue 3 全栈开发，对接微信支付 V3 沙箱环境，引入 Redis 和 RabbitMQ 做性能优化与异步处理。

**目标：** 做一个能写简历的完整电商项目，展示产品思维和技术深度。

## 4. 数据库设计（8 张表）

> 表结构已通过 MySQL 客户端创建完毕 ✅
> ⚠️ user 表已有注册数据；product 和 category 表需手动执行 `resources/db/init-data.sql` 初始化

### 4.1 用户表 `user`

```sql
CREATE TABLE `user` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT,
    `username`    VARCHAR(50)  NOT NULL UNIQUE,
    `password`    VARCHAR(255) NOT NULL COMMENT 'BCrypt 加密',
    `phone`       VARCHAR(20),
    `avatar`      VARCHAR(255),
    `role`        VARCHAR(20)  NOT NULL DEFAULT 'USER' COMMENT 'USER / ADMIN',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `is_deleted`  TINYINT DEFAULT 0 COMMENT '逻辑删除: 0-未删除 1-已删除',
    `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`)
);
```

### 4.2 分类表 `category`

```sql
CREATE TABLE `category` (
    `id`          BIGINT      NOT NULL AUTO_INCREMENT,
    `name`        VARCHAR(50) NOT NULL,
    `parent_id`   BIGINT      DEFAULT NULL COMMENT '父分类ID，0=一级分类',
    `level`       TINYINT     DEFAULT 1 COMMENT '层级：1=一级 2=二级',
    `sort`        INT         DEFAULT 0 COMMENT '排序序号',
    `create_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `update_time` DATETIME,
    `is_deleted`  TINYINT     DEFAULT 0,
    PRIMARY KEY (`id`)
);
```

### 4.3 商品表 `product`

```sql
CREATE TABLE `product` (
    `id`             BIGINT         NOT NULL AUTO_INCREMENT,
    `name`           VARCHAR(200)   NOT NULL,
    `description`    TEXT,
    `price`          DECIMAL(10,2)  NOT NULL COMMENT '现价',
    `original_price` DECIMAL(10,2)  COMMENT '原价（划线价）',
    `image`          VARCHAR(255)   COMMENT '商品主图',
    `images`         TEXT           COMMENT '多图 JSON 数组 ["url1","url2"]',
    `category_id`    BIGINT         NOT NULL,
    `category_name`  VARCHAR(50)    COMMENT '分类名称（冗余字段）',
    `sales`          INT            NOT NULL DEFAULT 0,
    `stock`          INT            NOT NULL DEFAULT 0,
    `rating`         DOUBLE         DEFAULT 0 COMMENT '评分 0-5',
    `status`         TINYINT        NOT NULL DEFAULT 0 COMMENT '0上架 1下架',
    `create_time`    DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `update_time`    DATETIME,
    `is_deleted`     TINYINT        DEFAULT 0,
    PRIMARY KEY (`id`),
    KEY `idx_category` (`category_id`),
    KEY `idx_status` (`status`)
);
```

### 4.4 购物车表 `cart`

```sql
CREATE TABLE `cart` (
    `id`         BIGINT NOT NULL AUTO_INCREMENT,
    `user_id`    BIGINT NOT NULL,
    `product_id` BIGINT NOT NULL,
    `quantity`   INT    NOT NULL DEFAULT 1,
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_product` (`user_id`, `product_id`)
);
```

### 4.5 订单表 `order`

```sql
CREATE TABLE `order` (
    `id`             BIGINT       NOT NULL AUTO_INCREMENT,
    `order_no`       VARCHAR(32)  NOT NULL UNIQUE COMMENT '订单号（yyyyMMddHHmmss+4位随机数，共18位）',
    `user_id`        BIGINT       NOT NULL,
    `total_amount`   DECIMAL(10,2) NOT NULL,
    `status`         TINYINT      NOT NULL DEFAULT 0 COMMENT '0待支付 1已支付 2已发货 3已完成 4已取消',
    `address_id`     BIGINT,
    `transaction_id` VARCHAR(64)  COMMENT '微信支付交易号',
    `prepay_id`      VARCHAR(64)  COMMENT '微信预支付ID',
    `pay_time`       DATETIME,
    `create_time`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `idx_user` (`user_id`),
    KEY `idx_order_no` (`order_no`),
    KEY `idx_status` (`status`)
);
```

### 4.6 订单项表 `order_item`

```sql
CREATE TABLE `order_item` (

    `order_id`   BIGINT         NOT NULL,
    `product_id` BIGINT         NOT NULL,
    `quantity`   INT            NOT NULL,
    `price`      DECIMAL(10,2)  NOT NULL COMMENT '下单时价格快照',
    PRIMARY KEY (`id`),
    KEY `idx_order` (`order_id`)

```

### 4.7 收货地址表 `address`

```sql
CREATE TABLE `address` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT,
    `user_id`     BIGINT       NOT NULL,
    `name`        VARCHAR(50)  NOT NULL COMMENT '收件人',
    `phone`       VARCHAR(20)  NOT NULL,
    `province`    VARCHAR(50)  NOT NULL,
    `city`        VARCHAR(50)  NOT NULL,
    `district`    VARCHAR(50),
    `detail`      VARCHAR(200) NOT NULL,
    `is_default`  TINYINT      DEFAULT 0,
    PRIMARY KEY (`id`),
    KEY `idx_user` (`user_id`)
);
```

### 4.8 支付流水表 `payment_log`

```sql
CREATE TABLE `payment_log` (
    `id`             BIGINT       NOT NULL AUTO_INCREMENT,
    `order_no`       VARCHAR(32)  NOT NULL,
    `transaction_id` VARCHAR(64),
    `pay_type`       VARCHAR(16)  COMMENT 'NATIVE / JSAPI',
    `total_fee`      INT          COMMENT '金额单位：分',
    `trade_state`    VARCHAR(32)  COMMENT 'SUCCESS/REFUND/NOTPAY/CLOSED',
    `notify_raw`     TEXT         COMMENT '微信回调原始报文',
    `create_time`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `idx_order_no` (`order_no`)
```

## 6. 认证架构（自定义 JWT 拦截器）✅ 已实现

**不使用 Spring Security**，采用轻量的自定义方案，更适合简历展示编码能力：

### 6.0 认证流程

```
请求 → JwtAuthInterceptor (HandlerInterceptor)
  ├─ 检查 Controller 方法是否有 @Auth 注解
  │   ├─ 无 @Auth → 放行（登录/注册等公开接口）
  │   └─ 有 @Auth → 从 Header 取 Bearer token
  │       ├─ token 无效/过期 → 返回 401 + Result.fail(UNAUTHORIZED)
  │       └─ token 有效 → 解析 userId → 存入 request attribute → 放行
  │
Controller 通过 @Auth 注解声明是否需要认证：
  @Auth  → 必须登录，拦截器注入 userId
  无注解 → 公开接口，无需 token

注册到 WebMvcConfig，排除路径：/api/user/login, /api/user/register,
  /api/product/list, /api/product/detail/**, /api/product/hot, /api/category/**
```

### 6.1 异常处理体系 ✅ 已实现

| 异常类型 | 处理方式 | HTTP 状态码 |
|---|---|---|
| `BusinessException`（业务异常） | `log.warn` + 返回业务错误码 | 200（业务内错误） |
| `MethodArgumentNotValidException`（`@Valid` 校验） | 收集字段错误信息 | 200 |
| `ConstraintViolationException`（参数校验） | 返回参数错误 | 200 |
| `DataAccessException`（数据库异常） | `log.error` | 200（code=5001） |
| `Exception`（兜底） | `log.error` + 500 状态 | **500** |

## 7. 核心业务流程 ✅ 已完成

```
用户浏览商品 → 加入购物车 → 去结算 → 弹窗选地址（可新增）
→ 提交订单 → 查看订单详情（展示地址）→ 发货前可改地址 → 等待支付对接...

或：商品详情页 → 选数量 → 立即购买 → 自动加购物车 → 跳转购物车结算
```

### 7.2 下单流程 ✅

```
ProductDetail.vue: handleBuyNow()
  → 检查登录
  → cartStore.addItem(productId, quantity)  // 先加购物车
  → router.push({ name: 'Cart' })           // 再跳购物车

Cart.vue: handleCheckout()
  → 弹出地址选择弹窗（默认地址预选中）
  → 用户手动选地址（或点"+ 添加新地址"填表单）
  → 确认下单

Controller: OrderController.create(OrderCreateDTO)
  → @Valid 校验参数 → 调 OrderService.createOrder()

Service: OrderServiceImpl.createOrder(userId, addressId, productIds)
  → 1. 查购物车列表
  → 2. 按 productIds 过滤（只处理选中商品）
  → 3. 检查库存（stock >= quantity）
  → 4. 生成订单号（yyyyMMddHHmmss + 4位随机）
  → 5. 计算总金额（取数据库价格，不信任前端）
  → 6. 创建订单（status=0 待支付）
  → 7. 批量创建订单项（价格快照）
  → 8. 扣减库存（乐观锁 WHERE stock >= quantity）
  → 9. 只删除已结算的购物车商品（未勾选的保留）
  → 10. 返回 OrderVO（含地址信息）
```

### 7.3 微信支付流程 ⏳

```
用户点击「去支付」
  → POST /api/order/pay/{id}
  → OrderController.pay()
    → OrderService.pay(orderId)
      → 校验订单状态（必须待支付）
      → WechatPayService.createOrder(orderNo, totalFee)
        → 构造请求 → 签名 → 调微信统一下单API
        → 获取 code_url → 保存 prepay_id
        → 返回 PayVO { codeUrl }
  → 前端渲染二维码（qrcode.js）
  → 用户扫码支付
  → 微信回调 POST /api/pay/notify
    → PayNotifyController.notify()
      → 验签（RSA-SHA256）
      → 解析 transaction_id
      → OrderService.handlePaid(orderNo)
        → 更新 status=1（已支付）
        → 写入 transaction_id, pay_time
        → 写入 payment_log
        → 返回 SUCCESS 给微信
  → 前端轮询 GET /api/order/status/{id} → 跳转成功页
```

### 7.4 超时取消流程 ⏳

```
订单创建 → RabbitMQ 延迟队列（30分钟）
  → 查询订单状态
  → 如果 status=0（待支付）→ 更新为 4（已取消）
  → 如果有扣库存 → 回滚库存
```

## 10. 代码规范（MVC 红线）

| 层 | 可以做 ✅ | 不可以做 ❌ |
|---|---|---|
| **Controller** | 接收参数、@Valid 校验、调 Service、包装 Result | 写业务判断、直接调 Mapper、操作 HttpSession |
| **Service** | 业务逻辑、事务（@Transactional）、缓存、调 Mapper、Entity↔VO 转换 | 返回 Entity 给 Controller、处理 HttpServletRequest、SQL 拼接 |
| **Mapper** | SQL 查询、MyBatis-Plus 条件构造 | 业务逻辑判断 |
| **Entity** | 映射表结构，仅字段+注解 | 包含业务方法、直接返回前端 |
| **VO** | 定义前端需要的字段 | 包含敏感字段（密码） |
