## 1. 项目概述

众乐电子商城是一个轻量级 B2C 电商平台，包含用户端（商品浏览/购物车/下单/微信扫码支付）和管理后台（商品/订单/用户管理）。项目采用 Java Spring Boot 3 + Vue 3 全栈开发，对接微信支付 V3 沙箱环境，引入 Redis 和 RabbitMQ 做性能优化与异步处理。

**目标：** 做一个能写简历的完整电商项目，展示产品思维和技术深度。

---

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 后端框架 | Java 17+ / Spring Boot 3.x |
| 安全认证 | 自定义 JWT 拦截器（@Auth 注解 + HandlerInterceptor） |
| ORM | MyBatis-Plus（含代码生成器） |
| 数据库 | MySQL 8.x |
| 缓存 | Redis (Spring Cache + RedisTemplate) |
| 消息队列 | RabbitMQ |
| 支付 | 微信支付 V3 API（NATIVE 模式，沙箱环境） |
| 前端 | Vue 3 + Vite + Pinia + Vue Router + Element Plus |
| 构建 | Maven |
| 部署 | Docker + docker-compose（MySQL + Redis + RabbitMQ + Backend + Nginx） |
| 内网穿透 | ngrok（开发时接收微信支付回调） |

## 4. 数据库设计（8 张表）

### 4.1 用户表 `user`

```sql
CREATE TABLE `user` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT,
    `username`    VARCHAR(50)  NOT NULL UNIQUE,
    `password`    VARCHAR(255) NOT NULL COMMENT 'BCrypt 加密',
    `phone`       VARCHAR(20),
    `avatar`      VARCHAR(255),
    `role`        VARCHAR(20)  NOT NULL DEFAULT 'USER' COMMENT 'USER / ADMIN',
    `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`)
);
```

### 4.2 分类表 `category`

```sql
CREATE TABLE `category` (
    `id`        BIGINT      NOT NULL AUTO_INCREMENT,
    `name`      VARCHAR(50) NOT NULL,
    `parent_id` BIGINT      DEFAULT NULL COMMENT '父分类ID，支持多级',
    `sort`      INT         DEFAULT 0,
```

### 4.3 商品表 `product`

```sql
CREATE TABLE `product` (
    `id`          BIGINT         NOT NULL AUTO_INCREMENT,
    `name`        VARCHAR(200)   NOT NULL,
    `description` TEXT,

    PRIMARY KEY (`id`),
    KEY `idx_category` (`category_id`),
```

### 4.4 购物车表 `cart`

## 6. 认证架构（自定义 JWT 拦截器）

**不使用 Spring Security**，采用轻量的自定义方案，更适合简历展示编码能力：

### 6.0 认证流程

```
请求 → JwtAuthInterceptor (HandlerInterceptor)
  ├─ 检查 Controller 方法是否有 @Auth 注解
  │   ├─ 无 @Auth → 放行（登录/注册等公开接口）
  │   └─ 有 @Auth → 从 Header 取 Bearer token
  │       ├─ token 无效/过期 → 返回 401 + Result.fail(UNAUTHORIZED)
  │       └─ token 有效 → 解析 userId → 存入 request attribute → 放行
  │
Controller 通过 @Auth 注解声明是否需要认证：
  @Auth  → 必须登录，拦截器注入 userId
  无注解 → 公开接口，无需 token

注册到 WebMvcConfig，排除路径：/api/user/login, /api/user/register
```

## 7. 核心业务流程

```
用户浏览商品 → 加入购物车 → 去结算 → 选择地址
→ 提交订单 → 微信扫码支付 → 支付回调 → 查看订单
```

### 7.2 下单流程（含消息队列）

```
Controller: OrderController.create(OrderCreateDTO)
  → @Valid 校验参数 → 调 OrderService.createOrder()

Service: OrderServiceImpl.createOrder(dto)
  → 1. 计算总价（查商品最新价格）
  → 2. 创建订单（status=0 待支付）
  → 3. 创建订单项（价格快照）
  → 4. 清空购物车中对应商品
  → 5. orderPublisher.publish → RabbitMQ
  → 6. 返回 OrderVO

RabbitMQ Consumer 异步:
  → 1. 查库存
  → 2. 扣库存
  → 3. 记录操作日志
```

### 7.3 微信支付流程

```
用户点击「去支付」
  → POST /api/order/pay/{id}
  → OrderController.pay()
    → OrderService.pay(orderId)
      → 校验订单状态（必须待支付）
      → WechatPayService.createOrder(orderNo, totalFee)
        → 构造请求 → 签名 → 调微信统一下单API
        → 获取 code_url → 保存 prepay_id
        → 返回 PayVO { codeUrl }
  → 前端渲染二维码（qrcode.js）
  → 用户扫码支付
  → 微信回调 POST /api/pay/notify
    → PayNotifyController.notify()
      → 验签（RSA-SHA256）
      → 解析 transaction_id
      → OrderService.handlePaid(orderNo)
        → 更新 status=1（已支付）
        → 写入 transaction_id, pay_time
        → 写入 payment_log
        → 返回 SUCCESS 给微信
  → 前端轮询 GET /api/order/status/{id} → 跳转成功页
```

### 7.4 超时取消流程

```
订单创建 → RabbitMQ 延迟队列（30分钟）
  → 查询订单状态
  → 如果 status=0（待支付）→ 更新为 4（已取消）
  → 如果有扣库存 → 回滚库存
```

## 8. Redis 缓存设计

缓存全部在 Service 层实现，Controller 不感知。

| 场景 | 数据结构 | Key | TTL | 策略 |
|---|---|---|---|---|
| 商品详情 | String | `product:detail:{id}` | 30 min | 读时回填，写时清除 |
| 热门商品榜 | ZSet | `product:hot` | 1 h | 定时刷新，按销量排序 |
| 分类树 | String | `category:tree` | 1 h | 读时回填 |
| 购物车 | Hash | `cart:{userId}` | - | 用户维度的购物车 |

### 9.2 开发 vs 生产环境

| 场景 | 前端访问方式 | API 路径 |
|------|-------------|---------|
| **开发** | Vite Dev Server（端口 3000） | Vite proxy → `/api` → `localhost:8074` |
| **生产** | Nginx 直接 serving 静态文件 | Nginx proxy_pass → `/api` → `backend:8074` |

### 9.3 Docker 容器编排（docker-compose.yml）

| 服务 | 镜像 | 内部端口 | 外部端口 |
|------|------|---------|---------|
| mysql | mysql:8.0 | 3306 | 3306 |
| redis | redis:7-alpine | 6379 | 6379 |
| rabbitmq | rabbitmq:3.13-management | 5672 / 15672 | 5672 / 15672 |
| backend | 自建 Dockerfile | 8074 | 8074 |
| nginx | nginx:1.27-alpine | 80 | 80 |

### 9.4 Nginx 配置要点

- **SPA 路由**：`try_files $uri $uri/ /index.html` 确保前端路由刷新不 404
- **Gzip 压缩**：对 JS/CSS/JSON 等开启，减小传输体积
- **API 代理**：`proxy_pass http://backend:8074` 将 `/api/` 请求转发到后端
- **静态缓存**：图片字体等设置 7 天强缓存
- **支付回调**：超时时间设为 60s，避免微信回调时断连

## 10. 代码规范（MVC 红线）

| 层 | 可以做 ✅ | 不可以做 ❌ |
|---|---|---|
| **Controller** | 接收参数、@Valid 校验、调 Service、包装 Result | 写业务判断、直接调 Mapper、操作 HttpSession |
| **Service** | 业务逻辑、事务（@Transactional）、缓存、调 Mapper、Entity↔VO 转换 | 返回 Entity 给 Controller、处理 HttpServletRequest、SQL 拼接 |
| **Mapper** | SQL 查询、MyBatis-Plus 条件构造 | 业务逻辑判断 |
| **Entity** | 映射表结构，仅字段+注解 | 包含业务方法、直接返回前端 |
| **VO** | 定义前端需要的字段 | 包含敏感字段（密码） |
